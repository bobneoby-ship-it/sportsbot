================================================================================
                         AUTO BET INTEGRATION
================================================================================

WHEN USER PLACES BET:

1. WhatsApp User Types: "BET 100 Real Madrid"
   ↓
2. Bot receives message via Twilio
   ↓
3. Verifies balance (user has $100+)
   ↓
4. Encrypts payload with AES-256:
   {
     "amount": 100,
     "team": "Real Madrid",
     "odds": 1.92,
     "betApiKey": "...",
     "gameType": "1x2"
   }
   ↓
5. Sends to mninetoto.com/Bet/PlaceBetForBot
   ↓
6. Receives ticket confirmation:
   {
     "success": true,
     "ticket": "TKT-20260730-001",
     "amount": 100,
     "odds": 1.92,
     "potential_win": 192
   }
   ↓
7. Deducts $100 from user balance
   ↓
8. Records bet in database:
   - Status: PENDING
   - Ticket: TKT-20260730-001
   - Amount: $100
   - Odds: 1.92
   ↓
9. Responds to user:
   "BET PLACED!
    Team: Real Madrid
    Amount: $100 USDT
    Odds: 1.92
    Potential Win: $192
    Your Balance: $900
    Ticket: TKT-20260730-001"

WEB DASHBOARD SAME PROCESS:
- User clicks "Place Bet"
- Enters team & amount
- Frontend sends POST /api/bet/place-real
- API calls same Auto Bet endpoint
- User gets confirmation with ticket
