WINDOWS TASK SCHEDULER METHOD:
------------------------------
1. Press Windows+R
2. Type: taskschd.msc
3. Click "Create Basic Task"
4. Name: "Sports Bot"
5. Trigger: "At startup"
6. Action: "Start a program"
7. Program: C:\path\to\start_all_services.bat
8. Check "Run with highest privileges"
9. Click OK

TROUBLESHOOTING:
================

WhatsApp not responding:
- Check bot is running (console window open)
- Check tunnel is active
- Wait 2-3 seconds for response

Web dashboard not loading:
- Check API is running
- Try: http://localhost:8900
- Check firewall allows port 8900

Bets not placing:
- Check Auto Bet API credentials in .env.groq
- Check internet connection
- Check balance is sufficient
- Check team name is correct

Services keep crashing:
- Install dependencies: pip install -r requirements.txt
- Check Python version: python --version (need 3.8+)
- Check .env.groq file exists with all credentials
