================================================================================
                    HOW IT WORKS
================================================================================

WHATSAPP FLOW:
  User sends message to +1 415 523 8886
    ↓
  Twilio receives message
    ↓
  Twilio calls bot webhook
    ↓
  sports_bot_final_production.py processes
    ↓
  Bot fetches real data (data_fetcher.py)
    ↓
  Bot compiles answer
    ↓
  Twilio sends response back
    ↓
  User receives answer

Response time: 3-5 seconds
All data: LIVE (no hardcoding)


WEB DASHBOARD FLOW:
  User opens: http://localhost:8900
    ↓
  index.html serves
    ↓
  User logs in (test_user / password123)
    ↓
  User types in chat or uses dashboard
    ↓
  Frontend calls api_dashboard.py
    ↓
  API calls sports_bot_final_production.py logic
    ↓
  Response returned to frontend
    ↓
  User sees result


BETTING FLOW:
  User: "BET 50 Real Madrid"
    ↓
  Bot checks balance ($50 available)
    ↓
  Bot gets odds (1.92)
    ↓
  Bot encrypts with AES-256
    ↓
  Bot sends to Auto Bet API (mninetoto.com)
    ↓
  Auto Bet confirms with ticket
    ↓
  Bot deducts $50 from balance
    ↓
  User gets confirmation with ticket
    ↓
  Bet tracked in database


DATA FETCHING FLOW:
  User: "How many times did Real Madrid win Champions League?"
    ↓
  Bot identifies: historical question
    ↓
  data_fetcher.py tries (in order):
    1. Wikipedia API (official records)
    2. ESPN API (sports data)
    3. BBC Sport (news/scraping)
    4. DuckDuckGo (search)
    5. Groq LLM (analysis)
    ↓
  First successful source returns answer
    ↓
  Bot sends answer with source
    ↓
  User gets real, detailed answer
    ↓
  ALL data LIVE - NO HARDCODING!
