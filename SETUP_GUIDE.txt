HOW IT WORKS:
=============

User Flow:
  1. User sends WhatsApp message
  2. Twilio forwards to bot (port 8899)
  3. Bot processes message
  4. Bot fetches real data (Wikipedia/ESPN/BBC)
  5. Bot sends response to user
  6. User data saved to database
  7. Dashboard shows updated info

Data Sources:
  - Wikipedia API (historical & tournament data)
  - ESPN API (live scores & standings)
  - BBC Sport (web scraping, current news)
  - DuckDuckGo (real-time web search)
  - Groq LLM (intelligent analysis)

TROUBLESHOOTING:
================

Bot not responding on WhatsApp?
  - Check tunnel is running
  - Check Twilio webhook URL
  - Check bot is running (port 8899)
  - Restart services

Dashboard won't load?
  - Check API is running (port 8900)
  - Check tunnel is active
  - Check browser console for errors

No data from APIs?
  - Check internet connection
  - Check .env.groq has valid API keys
  - Check Groq API key is active

Database errors?
  - Check users.db file exists
  - Check disk space
  - Check file permissions

Tunnel URL keeps changing?
  - Use named Cloudflare tunnel for production
  - Or set it in Twilio permanently
