DEPLOYMENT STEPS (30 Minutes):
==============================

STEP 1: Deploy to Cloud (5-10 minutes)

Option A: Render.com (RECOMMENDED - Completely Free!)
  1. Go to: https://render.com
  2. Sign up with GitHub
  3. Click "New+" → "Web Service"
  4. Connect: https://github.com/bobneoby-ship-it/sportsbot
  5. Set:
     Name: sports-bot
     Build: pip install -r requirements.txt
     Start: uvicorn sports_bot_final_production:app --host 0.0.0.0 --port 8899
  6. Add Environment Variables (from your .env.groq):
     - GROQ_API_KEY
     - TWILIO_ACCOUNT_SID
     - TWILIO_AUTH_TOKEN
     - TWILIO_WHATSAPP_NUMBER
     - HERMES_HOST = 0.0.0.0
     - HERMES_PORT = 8899
  7. Deploy!
  8. Get URL: https://sports-bot-xxxx.onrender.com

Option B: Railway.app or Heroku (Also free)
  Similar steps, same env variables


STEP 2: Update Twilio Webhook (2 minutes)

  1. Go to: https://console.twilio.com
  2. Login to your account
  3. Messaging → WhatsApp → Sandbox Settings
  4. Find "When a message comes in"
  5. Set URL to: https://sports-bot-xxxx.onrender.com/twilio
  6. Method: POST
  7. Save!


STEP 3: Test (1 minute)

  1. Open WhatsApp
  2. Save: +1 415 523 8886
  3. Send: "help"
  4. Wait 2-3 seconds
  5. Bot responds from CLOUD!

TROUBLESHOOTING:
=================

  - Check deployment successful
  - Check webhook URL correct
  - Check environment variables set
  - Wait 2-3 seconds

Wrong answer?
  - Bot fetches real data
  - Try rephrasing question
  - Try different question

Slow response?
  - Normal: 3-5 seconds
  - APIs take time
  - Check internet

  - Check internet
  - Check API status
